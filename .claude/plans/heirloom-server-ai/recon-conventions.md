# Heirloom Server AI — Reconnaissance Findings

## 1. System Config

**Location**: `server/src/dtos/config.dto.ts` (DTO) — server-side Zod schema
**Structure**: Machine learning config uses nested object with enabled/urls arrays
- `machineLearning.enabled` (boolean)
- `machineLearning.urls` (string array, min 1)
- `machineLearning.availabilityChecks.enabled|timeout|interval`
- `machineLearning.clip.modelName` (string), inherited from `AdminConfigMachineLearningModelSchema`
- `machineLearning.facialRecognition.modelName`, `minScore` (0.1–1), `maxDistance` (0.1–2), `minFaces` (≥1)
- `machineLearning.duplicateDetection.maxDistance` (0.001–0.1)
- `machineLearning.ocr.modelName`, `maxResolution`, `minDetectionScore`, `minRecognitionScore`
- Job concurrency: `AdminConfigJobSettingsSchema` — `{ concurrency: int ≥1 }` per queue
- Config update flow: validation decorators (`@IsBoolean`, etc.), repository caches via `systemConfigManager`, config init events trigger ML model sync

## 2. Jobs

**Queue enum**: `server/src/enum.ts:844` — `QueueName` (ThumbnailGeneration, MetadataExtraction, SmartSearch, FaceDetection, FacialRecognition, DuplicateDetection, Ocr, IntegrityCheck, etc.)
**Job enum**: `server/src/enum.ts:879` — `JobName` (AssetDetectFacesQueueAll, SmartSearchQueueAll, OcrQueueAll, etc.; QueueAll = bulk enqueue, singular = single job)
**Handler registration**: `@OnJob({ name: JobName.SmartSearch, queue: QueueName.SmartSearch })` decorator on service methods — e.g., `SmartInfoService.handleEncodeClip()` at line 88
**Asset job status table**: `server/src/schema/tables/asset-job-status.table.ts` — tracks per-asset job completion with nullable timestamps: `facesRecognizedAt`, `metadataExtractedAt`, `duplicatesDetectedAt`, `ocrAt`
**Missing query**: Uses `IS NULL` timestamp columns to find assets needing processing

## 3. ML Client

**Repository**: `server/src/repositories/machine-learning.repository.ts`
**Request format**: POST `/predict` with FormData; model task/type/options structured as nested JSON object
- `ModelTask.SEARCH` (clip), `FACIAL_RECOGNITION`, `OCR`
- `ModelType.VISUAL`, `TEXTUAL`, `DETECTION`, `RECOGNITION`, `OCR`
- Model name passed via `modelName` field; detection/recognition options (minScore, maxResolution) nested under `options`
**Example**: Clip visual = `{ "clip": { "visual": { "modelName": "...", ...payload } } }`
**Dimension changes**: Search repo handles clip embed dimension size — setDimensionSize/getDimensionSize calls when model changes; embeddings cleared if model swapped
