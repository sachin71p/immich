## Deviations
`scripts/gen-api.sh` copies `../../open-api/immich-openapi-specs.json` into the generator's required
`openapi.yaml` input before each core build. The copied input is ignored; the build-plugin output remains
uncommitted. This is the brief's permitted pre-generation approach and avoids duplicating the upstream spec.

The verifier now puts Clang's module cache under `native-apple/.build/`, an ignored project-local location.
The package uses string deployment targets (`"26.1"` and `"26.0"`) because the installed PackageDescription
API does not define `.v26`; this preserves the requested deployment targets.

## Verification
Ran `native-apple/scripts/verify.sh core` after the cache and platform corrections. The previous cache
permission failure is gone; SwiftPM now fails linking its manifest against the mismatched host
Command Line Tools SDK/compiler. The host lacks a full Xcode developer directory and `xcodegen` is absent.
`git diff --check` and entitlement plist validation pass.
