# S6 handoff — Sync stream for spaces & shared external libraries

## Summary
- Added shared-space and shared-library sync request/entity types, DTOs, ordering, handlers, checkpoints, member backfills, asset/exif streams, and audit-driven container/asset removals.
- `SyncAssetV1/V2.spaceId` is additive/optional. Flutter only parses requested known entity types, so it ignores new stream types; the generated model decoder accepts map fields without an unknown-field rejection path in `mobile/lib`.
- Space/library streams exclude requester-owned assets, retain real global favorites, and emit a cursor even for an initially empty membership so later membership uses backfill.
