# S7 handoff — Full metadata endpoint & extended search filters

## Summary
- Added `GET /assets/:id/exif/full`, gated by `AssetRead`; it reads original plus sidecar EXIF, groups family-1 keys,
  strips binary values to `{ binary: true, bytes }`, and returns 404 for offline external assets.
- Added legacy and V3 metadata filters for ISO, f-number, focal length, file size, dimensions, extension/MIME,
  projection, location, orientation, and FPS. Search suggestions now include scoped file extensions.
