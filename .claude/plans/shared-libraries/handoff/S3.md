# S3 handoff — Storage keys & relocation engine

## Summary
Added space-aware storage keys, a queued relocation worker with crash-safe StorageCore moves, storage-template
space roots/public per-asset mover, external-library scan/unlink/offline guards, upload destination validation,
and reserved `shared` user-label validation.

## Deviations
- `requestRelocation(..., trx?)` inserts via the supplied Kysely transaction and returns a `queueAfterCommit`
  callback; callers invoke that callback only after the outer transaction succeeds (Kysely has no commit hook).
- Relocation's template call uses a storage-template singleton initialized at ConfigInit to avoid adding a new
  dependency to every BaseService constructor.
