## 2. Fixture image approach

- **Ids**: every fixture asset id starts with `fx` (`fx000001…`, generated `fx%06d`, live-motion
  partners `fxM%06d`). `FixtureArtwork.isFixtureAsset` is a prefix check, so no threading of
  fixture flags through view code and no signature changes (`SearchView` still compiles untouched).
- **Generated images**: `UIGraphicsImageRenderer`, solid fill at a stable hue per id (djb2, so it
  is deterministic across launches) plus a large white index number (trailing digit run of the id).
  Rendered at the asset's own aspect ratio (long edge 512), memoized in a lock-guarded 200-entry
  cache (`ArtCache`, `@unchecked Sendable` — `NSCache` is not `Sendable` under Swift 6).
- **Thumbhashes**: four real vectors from PhotosCore's golden file
  (`Tests/Fixtures/thumbhash-vectors.json`), picked by hue family so placeholder and full art hues
  agree. Because `MediaPipeline.stream` yields the thumbhash placeholder first, album covers,
  viewer pages and search cells render non-blank through production code with zero changes there.
- **Serving path** (no PhotosCore change): the grid cell paints the generated image directly,
  warms the pipeline *memory* cache at thumbnail/preview/fullsize tiers, and skips the network
  load for fixture ids. Covers and viewer then resolve through the real `pipeline.load`.
  The seed additionally renders thumbnails into the pipeline *disk* cache
  (`TieredMediaCache.store`, same `fixture-media-cache` root `startFixture` uses) — see Root
  causes §5.1. Library prefetch skips fixture ids.
- **Mix**: default world 12 stills + 1 motion partner — portrait/landscape/panorama, videos
  0:07 (`durationSeconds: 7`) and 1:05:03 (`3903`), one live photo (`livePhotoVideoId`, partner
  hidden from the timeline by the store), 2 favorites, personal/space/s1/s2/library-L1/locked
  containers, one GPS exif (Places). `-fixtureSeedCount=<N>` (parsed in `FixtureSeed.seedCount`,
  clamped 1…150000) generates N assets over a 15-year date spread cycling the same mix, chunked
  `apply()` batches of 5000, album links capped at 5000; motion partners ride alongside (total
  slightly above N at large counts).

## 5. Root causes found

1. **Fixture boot stall (found via device log, fixed).** After expanding the seed, A3 failed its
   30 s launch assert although the world was correct. Simulator log showed
   `fetch failed for fx000001 tier thumbnail … NSURLErrorDomain Code=-1001` ~60 s after launch:
   `refresh()` → extension snapshot writer `await`s `pipeline.load(.thumbnail)` for the 4 most
   recent favorites *before any grid cell exists*, and each load hung on a ~60 s connect timeout
   to `https://fixture.local` (the old world had no favorites, so nothing loaded). Fix: seed-time
   disk-cache pre-warm of those thumbnails (plus prefetch fixture-skip). Boot is back to seconds;
   A3 green. No AppSession/PhotosCore change needed.
2. **L2 mechanism (code-confirmed)**: `.task(id: source-timelineVersion)` restarts cancel
   in-flight `loader.load`, and the `reload()` catch set the cancellation text as a permanent
   banner (same text in Settings via `session.lastError`).
3. **L3/L5 mechanisms (code-confirmed)**: `selectedBackgroundView` behind image-filled
   `contentView`; headers only configured in `supplementaryViewProvider`, never on editMode flips.
4. **Tour harness XCUITest lessons** (each found via a failing run + xcresult forensics):
   - an open SwiftUI `Menu` removes its label from the hierarchy — dismiss by tapping a menu
     item ("Both Libraries", a no-op reselect), never by re-tapping the label;
   - `swipeDown()` only bounces a medium/large-detent sheet between detents — drag from the
     grabber to the bottom (`dismissSheet`), and guard later taps on the sheet being gone (the
     stuck Info sheet otherwise poisons every later step);
   - the search field's clear (x) button carries the label "Close" — scope viewer-Close by
     excluding identifier `xmark.circle.fill` (`closeViewer`);
   - tab-bar taps silently no-op while the software keyboard is up (it overlaps the tab bar) —
     tap keyboard Return after typing (`dismissKeyboard`), and verify every tab arrival with
     retry (`goTab`), failing loudly instead of screenshotting the wrong screen;
   - below-the-fold rows need scroll-to-tap (`tapScrolling`); "Trip" lives under Shared Albums
     (2 members); tab-bar *identifiers* are intermittently absent, so match tabs by label
     (in-tree precedent from SyncUITests).
